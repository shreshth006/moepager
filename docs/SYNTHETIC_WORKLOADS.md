# Synthetic Workload Generation: Math & Formulation

Mathematical parameterization of synthetic MoE access traces generated by `mp-synth`.

## Access Distributions
1. **Per-Layer Popularity Skew**: Modeled via Zipf distributions with shape parameter $\alpha \in [0.8, 1.4]$.
2. **Cross-Layer Affinity**: Transition probabilities $P(e_{l+1} \mid e_l)$ with Dirichlet smoothing.
3. **Temporal Reuse**: Short-term burstiness modeled using moving Dirichlet-Multinomial urn models.
